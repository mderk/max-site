# index.html — personal site-card

Mode: Persuade. Audience: contract clients and hiring teams (mixed). Action: email (primary), CV PDF / LinkedIn / GitHub (secondary). Languages EN + ES, toggle. Content source: CV only; NDA employers stay unnamed. Pending from user: photo file, Impossible Rocks URL, Telegram handle.

## Direction contract

THESIS: The site is one session on a green-phosphor terminal (amber in the first build; user switched to a calmer green), but set for reading, not for show-off: big type, full contrast, plain human sentences. Refuses the category default (hero + photo + icon cards + skills bars) and the hacker cliché (green matrix, tiny mono, glitch).

OWN-WORLD: Green-black glass (#0b100c) with a soft, desaturated green phosphor (#86d39b, highlight #cdf0d6) as the only hue, deliberately calm, not matrix-neon; brightness is the only other variable. Inverse-video status line on top, Midnight-Commander style numbered key bar at the bottom. VT323 for display, Azeret Mono for reading text. Faint scanlines and tube vignette, no noise, no neon. Only the active line blooms; older history rows dim like phosphor persistence. Raises: current job glows, past fades (neon); first screen indexes every section by key, keys work (sewing pattern); type size follows the weight of the fact (telop); honest status line with uptime since 1998 and Girona local time (cyworld).

STORY: Visitor sees who, since when, what now, and how to write in one screen; scrolls through whoami, now, history (newest bright → 1998 dim), projects, stack, contact. Leaves by emailing or taking the CV.

FIRST VIEWPORT: Top inverse status line (host, uptime, local time, availability, EN/ES). Left-aligned: MAXIM DERKACHEV on one line in VT323 at clamp(2.6rem, 6.4vw, 5.25rem) (user asked for smaller, single line), intro stressing breadth, availability line, two actions [5 Write to me] [6 CV.pdf], blinking block cursor. Main links (github, linkedin, impossible.rocks) in a right column on wide screens, a row below on narrow. Bottom fixed key bar 1–7.

FORM: Amber VT220 terminal, candidate 5 of 7 on the grounded list; user chose it explicitly after a re-roll. Seed key 9e7c8a3e. Code-led (no image generation). Signature interaction: CRT power-on (tube line expands, lines print in sequence) and keyboard navigation via the key bar with the active key lit.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
